# Web Development Projects

This repository contains two web development projects created using **HTML, CSS, and JavaScript**: a modern tribute website dedicated to **Lata Mangeshkar** and an interactive **Calculator**.

## Projects

### 1. Lata Mangeshkar Tribute Website

A modern and responsive tribute website celebrating the life, career, achievements, and legacy of legendary Indian playback singer **Lata Mangeshkar**.

**Features:**

* Responsive navigation bar
* Attractive hero section
* Biography and early-life section
* Career journey and major milestones
* Awards and achievements section
* Popular songs section
* Image gallery
* Inspirational quotes and tribute message
* Clean and modern user interface

### 2. Calculator

A responsive and interactive calculator that supports both basic and scientific calculations.

**Features:**

* Basic arithmetic operations
* Scientific calculation mode
* Light and dark theme toggle
* Clear and delete functions
* Responsive design
* Interactive buttons
* Simple and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the required project folder.
3. Open its `.html` file in any modern web browser.

No additional software or installation is required.
